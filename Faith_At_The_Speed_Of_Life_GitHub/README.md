# Faith At The Speed Of Life website

## Publish with GitHub Pages

1. Upload `index.html` and the complete `images` folder to the root of your GitHub Pages repository.
2. Commit the changes.
3. In repository Settings → Pages, confirm the publishing source matches your repository setup.

## Hero banner

`images/hero-banner.jpg` uses the hero artwork you supplied. The embedded sample navigation strip was cropped from the top so your website's real, accessible navigation remains functional. The banner scales to the available screen width.

## Book covers

The gallery uses the original cover images in `images/books/`. Keep the folder structure unchanged when uploading.
